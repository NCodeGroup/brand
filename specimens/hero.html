Secrets that clean up after themselves.

Pinned, pooled .NET buffers that zero their memory on dispose. For keys, passwords and anything else you don't want left behind on the heap.

Get started View on GitHub
$ dotnet add package NCode.Buffers

01

Pinned.

The garbage collector never moves a sensitive buffer, so it never leaves a stale copy of a key behind.

02

Zeroed.

Disposing a buffer overwrites all of it, in a way the JIT cannot optimize away.

03

Pooled.

Buffers are reused, and each one is zeroed before another caller can rent it.
