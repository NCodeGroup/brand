Quick start

This page derives a key from a password, verifies an HMAC-SHA256 signature with it, and zeroes the derived key and the expected MAC when the method returns.

Install

$ dotnet add package NCode.Buffers Shell

Verify a signature

BufferFactory.Rent hands back a pinned, pooled buffer and an owner. Disposing the owner zeroes the whole buffer, so the key never outlives the method.

NoteRent hands back a span sliced to exactly the length you asked for, even when the pooled buffer behind it is larger.

CautionThere is no finalizer. A buffer that is never disposed is never zeroed, so always use using.

Choosing a buffer

API Use it when Pooled
Rent You need a temporary buffer for a key, password or other secret PooledYes
CreatePooledBufferWriter You write a secret whose length you don't know up front PooledYes
CreatePinnedArray An API needs a T[], within one synchronous scope PooledNo
GetSecureLifetime You already have the memory, usually stackalloc PooledNo
