The look and feel of NCode

Instrument

NCode's mark is a value held between the braces of code. Instrument builds every surface the same way: a neutral, precisely made case of engraved labels, keys and wells that holds live values, lit on screens and lamps, with the mark's own brace drawn around what one boundary holds.

Identity is infrastructure, so it should feel like well-made equipment: you can see what every part is, what state it is in, and which security boundary you are acting in, before you touch anything.

  1. 01

    The frame is fixed, the value is live

    Structure is stone and engraved type. Color belongs to values, to state and to the tenant, so the look survives any brand color.

  2. 02

    A brace marks a scope

    The mark's brace is drawn around what one boundary holds, and nowhere else. It is never decoration.

  3. 03

    Names are engraved, values are displayed

    A fixed part carries narrow capitals. Anything read off the system, an ID, a count, a date, code, is monospace.

  4. 04

    Depth means one thing

    A lip below: press it. A shade above: fill it. Flush: a plate. Hard edges only, no gradients, no glow.

  5. 05

    State is lit, and said

    A lamp or a lit plate always sits beside a word, and its shape changes with the state. Color never works alone.

  6. 06

    Hazards wear tape

    Test environments, cautions and the platform boundary carry amber and black stripes, in both themes.

  7. 07

    Keys travel, readouts tick

    A key moves two pixels in 70 milliseconds. A value changes in one step. Nothing else moves.

The brace

The one motif that comes straight from the mark. It is drawn from the mark's own geometry, never from a font, and it means one thing.

A brace marks a scope: it is drawn around what one named boundary holds, a security boundary or the lifetime of a secret, and nowhere else.

Construction

Straight stems, circular hooks, and a cusp whose tip is half the stroke high. build.mjs draws every brace.

The boundary plate

The kind and the name of a boundary between the mark's own braces: on the display, and wherever a dialog restates it
