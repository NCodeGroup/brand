# The Mark's Sources

[ncode.json](ncode.json) holds the geometry of the `{N}` mark, which build.mjs draws every file of
[logo/ncode/](../../logo/ncode/) and [brace/brace-mark.svg](../../brace/brace-mark.svg) from, and [kit.md](kit.md) is
the text of [logo/README.md](../../logo/README.md). Edit them here and run `npm run build`. The mark is NCode
Group's: [TRADEMARKS.md](../../TRADEMARKS.md) says how you may use it.
